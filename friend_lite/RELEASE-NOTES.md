Friend-clickable **Lite** setup for Windows 10/11.

1. Download `ViralForge-Lite-Portable.zip`
2. Unzip the folder
3. Double-click **Start.bat** (or ViralForgeSetup.bat)

Lite is pre-selected. Dry-run / Ken Burns cinema works offline — **no Wan or LTX weights are in this zip**. Regular and Maximum stay in the setup sidebar if you upgrade later.

Python is bundled. First launch copies local UI libraries from `vendor/wheels` (not a GPU model download).
